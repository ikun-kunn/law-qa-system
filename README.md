# 法律知识问答与条文溯源系统（教学演示）

这是 Java 21、Spring Boot、H2 与 Vue 3/Vite 的最小完整演示项目。法律内容只用于软件演示，不构成法律意见。演示库不代表完整或现行法律数据库；添加或引用真实条文前，应由使用者核验官方来源、版本及效力状态。

此前对话带来的《民法典》要约相关样例被标为“待人工核验”，数据库只收录其提及的第472—476条，并附官方法律法规数据库 PDF 来源链接。应用在答复中显示“演示资料，条文需核验”。没有匹配证据或未命中规则时会明确拒答。

## 运行

需要 JDK 21、Maven 3.9+、Node.js 20+。

1. 后端：在 `backend` 执行 `mvn spring-boot:run`，服务地址 `http://localhost:8080`。
2. 前端：在 `frontend` 执行 `npm install` 后 `npm run dev`，打开 Vite 输出的地址（默认 `http://localhost:5173`）。
3. H2 控制台：`http://localhost:8080/h2-console`，JDBC URL `jdbc:h2:mem:lawdemo`，用户名 `sa`，密码留空。

## 功能

- 条文关键词搜索与来源链接、版本和核验状态展示。
- 基于显式关键词规则的问答；仅在演示条文可提供证据时作答，其他问题拒答。
- 收藏（浏览器本地存储）、答复评分与反馈（后端内存接收）。
- 固定教学演示免责声明。

## 验收用例（15项）

1. 空搜索返回空结果。 2. 搜索“要约”命中第472条。 3. 搜索“撤销”命中第476条。 4. 搜索“邀请”命中第473条。 5. 搜索不存在的词返回空列表。 6. 问“什么是要约”返回有证据的答复。 7. 问“要约邀请是什么”引用第473条。 8. 问“要约撤销”引用第476条。 9. 无关问题返回拒答。 10. 空问题返回校验错误。 11. 每个答复含免责声明。 12. 搜索结果有官方来源链接。 13. 收藏接口可新增收藏。 14. 评分接受1—5分。 15. 超出评分范围返回校验错误。

自动化验收：`cd backend && mvn test`；前端构建：`cd frontend && npm run build`。
